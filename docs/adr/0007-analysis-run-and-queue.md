# ADR-0007: Запуск анализа и очередь рекомендаций

POST /api/analyses в рамках запроса считает оценки и сохраняет AnalysisRun со всеми входными данными; если embeddings не получены, запуск не создаётся. При наличии конкурентов ставится BullMQ-джоб с jobId, равным id запуска, и воркер дописывает рекомендации в тот же запуск.

## Компромиссы

- Оценки синхронные, рекомендации в фоне: форма не держит соединение на время генерации.
- Добавить конкурентов к посчитанным оценкам нельзя — это новый запуск с повторным расчётом embeddings.
- Состояние и причина ошибки джоба читаются из BullMQ, поля статуса в базе нет, чтобы не держать два источника правды. Запуск с конкурентами без рекомендаций и без джоба в Redis означает, что состояние задачи потеряно.
