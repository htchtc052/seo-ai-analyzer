# ADR-0005: Оценки из пакетных embeddings

Запрос и все фрагменты статьи векторизуются одним вызовом /v1/embeddings, оценка фрагмента — cosine similarity к запросу. Оценки разных embedding-моделей несравнимы: у каждой своя шкала близости.

- В базе хранятся только оценки фрагментов; общая оценка — среднее, считается при чтении. Embedding всей статьи не создаётся.
- Конкуренты и контекст в оценках не участвуют.
- Embeddings не кешируются: каждый запуск заново векторизует статью, для десятков абзацев это около секунды.
