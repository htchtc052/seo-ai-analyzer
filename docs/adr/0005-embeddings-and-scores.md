# ADR-0005: Пакетные embeddings и cosine similarity

Статус: принято.

OllamaService.embed() отправляет запрос и все фрагменты статьи одним вызовом /api/embed. RelevanceService считает cosine similarity каждого фрагмента к запросу.

- В Postgres хранятся только оценки фрагментов. Общая оценка — среднее, вычисляется при чтении.
- Отдельный embedding всей статьи не создаётся: общая оценка — производная от фрагментов, а не самостоятельная метрика.
- Конкуренты и контекст в оценках не участвуют, они нужны только рекомендациям.

Компромисс: embeddings не кешируются, поэтому каждый запуск заново векторизует статью. Для статей в десятки абзацев это около секунды.

Ollama работает рядом с приложением, адрес и модели задаются конфигурацией.
