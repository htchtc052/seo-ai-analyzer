# ADR-0002: Явные токены инъекции зависимостей

Каждая инъекция в конструкторе NestJS помечена @Inject(Класс). Тесты запускаются через tsx на esbuild, который не выпускает emitDecoratorMetadata: без явных токенов сборка Nest работает, а тесты падают на неразрешённых зависимостях. Удалять декоратор при рефакторинге нельзя.
