# ADR-0002: Явные токены инъекции зависимостей

Статус: принято.

Каждая инъекция класса в конструкторе NestJS помечена @Inject(Класс). Очереди инжектятся декоратором BullMQ.

Сборка Nest поддерживает emitDecoratorMetadata, но тесты запускаются через tsx на esbuild, который эту метадату не выпускает. Без явных токенов приложение работает, а тесты падают на неразрешённых зависимостях. Компромисс — лишний декоратор в каждом конструкторе; удалять его при рефакторинге нельзя.
