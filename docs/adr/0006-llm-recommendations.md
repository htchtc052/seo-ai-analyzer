# ADR-0006: Слои генерации рекомендаций

Статус: принято.

- OllamaService — HTTP-клиент без знания о домене: embed(texts) и chatStructured(prompt, schema).
- RelevanceService — embeddings и cosine similarity.
- RecommendationService — промпт и получение структурированного ответа.
- AnalysisService — сборка входных данных, запуск этапов и сохранение результата.

JSON Schema для ответа модели выводится из общей Zod-схемы через z.toJSONSchema() и передаётся в Ollama как format. Той же схемой проверяется полученный JSON, поэтому вторая, рукописная схема не нужна.

Модель вызывается с think: false. С режимом рассуждений ответ шёл около пяти минут, без него — около минуты при валидном JSON. Компромисс — рекомендации без предварительного рассуждения модели.

Модель получает фрагменты с оценками, тексты конкурентов, запрос и контекст. Валидный по схеме ответ не гарантирует фактической точности рекомендаций.
