# ADR-0001: Статья хранится и передаётся структурой, не HTML

HTML разбирается только при импорте. Статья хранится как sections: заголовок секции (null у вводной) и массив абзацев. Фронтенду нечего санитизировать, а просмотр, embeddings и LLM работают с одним сохранённым текстом. Компромисс — ссылки, выделения и таблицы исходной страницы теряются.

Абзацы берутся из листовых текстовых блоков — p, li, blockquote, pre и div без вложенных блоков, заголовки секций из h2 и h3. Одних p мало: у части сайтов текст лежит в div.

Оценки хранятся массивом в порядке абзацев статьи, поэтому порядок извлечения должен оставаться стабильным.
