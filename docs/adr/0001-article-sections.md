# ADR-0001: Статья передаётся на фронтенд структурой, не HTML

Статус: принято.

Бэкенд хранит и отдаёт статью как sections: заголовок секции и массив текстовых абзацев. У вводной секции heading равен null. Заголовок статьи — отдельное поле. React выводит строки обычным JSX.

Выбор: HTML разбирается только на бэкенде. Фронтенду нечего санитизировать, а просмотр, embeddings и LLM работают с одним и тем же сохранённым текстом. Компромисс: исходная разметка страницы (ссылки, выделения, таблицы) теряется.

Текст берётся из листовых текстовых блоков — p, li, blockquote, pre и div без вложенных блоков, заголовки секций — из h2 и h3. Одних p недостаточно: у части сайтов текст лежит в div.

Порядок фрагментов стабилен: оценки сохраняются массивом в том же порядке, что и абзацы статьи.
