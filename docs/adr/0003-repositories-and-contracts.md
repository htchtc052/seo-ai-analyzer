# ADR-0003: Репозитории и общие Zod-контракты

Статус: принято.

- Репозитории содержат обращения к Prisma, сервисы — бизнес-логику.
- Модули собраны по фичам. В корне модуля лежат только его строительные блоки Nest: module, controller, service, repository, processor. Вспомогательный код без DI (чистые функции, промпт, имя очереди и тип джоба, фабрика ошибки импорта) — в подпапке lib/ модуля.
- Zod-схемы в packages/contracts — единственное описание API: из них выводятся TypeScript-типы для бэкенда и React.
- Вход проверяется ZodValidationPipe. Исходящий ответ проверяет и очищает глобальный ZodSerializerInterceptor по схеме из @ResponseSchema(...) на методе контроллера.

Выбор против DTO-классов с class-validator и class-transformer: у фронтенда и бэкенда одна схема, и форма ответа не может разойтись между ними. Компромисс — стандартные декораторы Nest для валидации и сериализации не используются.
