# ADR-0008: Прод-окружение

- VPS не собирает код: GitHub Actions публикует образы api и web в GHCR, сервер скачивает их. Traefik держит один домен и направляет /api в API, остальное в nginx со статикой.
- Миграции применяет prisma migrate deploy во временном контейнере из образа api до пересоздания сервисов: та же версия Prisma, что у приложения, а при ошибке миграции работающие контейнеры остаются.
- Runtime-зависимости api ставятся с --omit=dev --omit=optional. Иначе npm ставит TypeScript и другие необязательные peer-зависимости Prisma; вместе с ними отпадают необязательные нативные ускорители, и BullMQ работает на JS-реализации.
- Ollama стоит на хосте, а не в compose, и слушает 0.0.0.0, чтобы до неё доходили контейнеры через host.docker.internal. Файрвола нет, порт 11434 открыт наружу — допустимо для учебного стенда.
