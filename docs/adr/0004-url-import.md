# ADR-0004: Импорт статей по URL

Fetch — синхронная операция: бэкенд скачивает страницу нативным fetch, Mozilla Readability на DOM из linkedom выделяет материал, результат сохраняется в Postgres. Страница принимается только с HTTP 200 и HTML-типом, лимиты — 10 секунд и 5 МБ; статья — от 500 символов текста и с заголовком.

## Компромиссы

- Скрипты не выполняются. Сайты, которые рендерят текст JavaScript или закрывают доступ ботам, не импортируются; первые отсекаются порогом длины.
- Каждый Fetch создаёт новую неизменяемую Article, даже для той же ссылки: тексты дублируются, зато не нужны версии и дедупликация.
- Своя статья и конкуренты — одна модель Article, роль задаётся связью с запуском.
- Импорт ходит по любому публичному адресу; ограничивать исходящие запросы — задача сети сервера.
- Ссылки-примеры в форме и ожидаемо успешные ссылки smoke-теста импорта берутся из одного файла packages/examples/topics.json, поэтому не расходятся. Smoke зависит от чужих сайтов и запускается вручную, вне npm test.
